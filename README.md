# Workspaces_ahk
基于 AutoHotkey v2 的 Windows 虚拟桌面管理工具：工作区切换、窗口自动跟随、可自定义 JSON 布局、可视化转盘选窗。

## 功能

- **4 个工作区**：热键切换、点击切换、滚轮切换
- **窗口自动跟随**：激活某窗口时若属于其他工作区，自动切换过去
- **窗口归属**：`Ctrl+Alt+数字` 把当前窗口移动到指定工作区
- **可自定义布局**：外部 JSON 文件定义任意数量的窗口排布（二分、三分、四宫格、L 型错位等）
- **可视化转盘**：侧边栏圆点滚轮预览布局，双击中间圆进入选取模式
- **冻结选取**：点击窗口依次选择，选中后应用布局；淡青绿高亮一闪即隐
- **自动提权**：脚本启动自动以管理员权限运行
- **任务栏兼容**：选取模式下可点击任务栏切换窗口后继续选取

## 热键

| 热键 | 功能 |
|---|---|
| `Alt + 1~4` | 切换到对应工作区 |
| `Ctrl + Alt + 1~4` | 把当前窗口移动到对应工作区 |
| `Alt + [` / `Alt + ]` | 上一个 / 下一个工作区 |
| `F9` | 重新加载布局 JSON |
| `F10` | 退出脚本 |
| `Esc` | 退出冻结选取模式 |

## 布局配置

布局定义在同目录的 `Workspaces.layouts.json`，首次启动自动生成模板。每个布局包含：

- `id`：布局编号（显示在转盘上）
- `name`：布局名称（仅日志用）
- `windows`：需要的窗口数量
- `cells`：每个窗口的位置 `[x, y, w, h]`，均为 `0.0 ~ 1.0` 的比例值

例如"左右二分"：

```json
{
  "id": 1,
  "name": "左右二分",
  "windows": 2,
  "cells": [[0.0, 0.0, 0.5, 1.0], [0.5, 0.0, 0.5, 1.0]]
}
```

v1.0.1更新：
 侧边栏现在可以拖动和吸附

侧边栏不再固定死在左上角。鼠标按住四个绿格中间的小方块（光标会变成小手），即可把整块面板拖到屏幕顶部或左侧边缘任意位置。拖动时面板四周会出现一圈琥珀色描边提示；松手后自动吸附到最近的边。位置会记在 `Workspaces.state.json`，下次启动还原到原处。

从屏幕抓取布局预设

不想再手动算每个窗口占多少比例了。**三击侧边栏**进入抓取模式，屏幕变暗，依次点击想要的窗口（按点击顺序记录），**再按三击侧边栏**保存——脚本读取这些窗口此刻的实际位置和大小，换算成相对比例，追加到 `Workspaces.layouts.json`，新预设自动取下一个可用编号，名字叫「预设 N」。
